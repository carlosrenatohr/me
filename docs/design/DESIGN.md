# Design System — Initial Direction

Status: Draft; must be refined after visual exploration and owner approval.

## Direction
Dark Editorial — independent, thoughtful, technical, restrained.

## Color exploration
Start with the candidates in `PERSONAL-DESIGN-PROFILE.md`. Explore:
- Main background: deepest navy.
- Secondary surfaces: dark navy/slate.
- Elevated surfaces: slightly lighter blue-gray.
- Primary text: soft cool white.
- Secondary text: accessible muted cool gray.
- Accent: restrained medium/light blue.
- Borders: subtle cool blue-gray.

Do not use the candidate values blindly. Validate contrast and hierarchy.

## Typography exploration
Compare at least two font pairings. Consider an editorial serif for display headlines, a readable sans-serif for body and UI, and a monospace for metadata. Verify licensing, loading strategy, and performance.

## Layout
- Desktop content width should be generous but controlled.
- Long-form reading width should remain comfortable.
- Use a consistent spacing scale and grid.
- Project imagery should be prominent.
- Avoid card overload and excessive rounded corners.

## Component principles
Build a small shared system: site header/footer, project card, project metadata, section heading, content blocks, buttons/links, tags, and responsive navigation.

This document is intentionally incomplete until the two visual directions are explored and one is approved.
