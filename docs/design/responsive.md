# Responsive Design Requirements

## Public site
- Mobile reading experience must be first-class.
- Navigation must work with keyboard and touch.
- Project imagery must preserve intentional crops.
- Long-form text must remain readable.
- No horizontal overflow.
- Avoid hiding essential project information on mobile.

## Target viewports
- Desktop: 1440 × 900
- Laptop: 1280 × 800
- Tablet: 768 × 1024
- Mobile: 390 × 844
- Small mobile: 360 × 800

## Verification
Capture and inspect Home, Projects, and Project Detail at minimum on desktop and mobile. Inspect About and Contact at mobile as well.
