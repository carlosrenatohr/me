# Interaction Requirements

- Navigation links have clear hover, focus, and active states.
- Focus indicators are visible against dark surfaces.
- Buttons and links communicate their purpose.
- Motion is subtle and respects `prefers-reduced-motion`.
- Mobile menu opens, closes, and supports keyboard interaction.
- Project cards have meaningful clickable areas without nesting interactive controls.
- External links are identified appropriately.
- Contact actions work; no fake form submission.
- CV download is only enabled when an approved file exists.
