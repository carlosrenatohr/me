# Content Model — V1

All content must be typed and validated. Exact fields may be refined during implementation, but maintain separation between content and presentation.

## Profile
- name
- professional headline
- short introduction
- longer biography
- location (only if owner approves)
- portrait (optional)
- email (only when supplied)
- LinkedIn URL
- GitHub URL
- CV file path (optional)

## Project
- title
- slug
- short summary
- category
- status: draft or published
- featured
- cover image
- period (verified)
- role (verified)
- technologies
- context/problem
- contribution
- approach
- technical decisions
- outcomes (verified)
- gallery (approved assets)
- external links (approved)

## Experience
- organization
- role
- start/end dates (verified)
- summary
- contributions (verified)
- technologies

## Content integrity
Do not invent values. Missing information must be represented as a TODO or content gap, not silently filled with plausible claims.
